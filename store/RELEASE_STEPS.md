# 公開までの手順（Android / Google Play）

上から順に進めます。「あなた」はオーナーさんの作業、「Claude」はこちらでやる作業です。

## 1. Google Play の開発者登録（あなた）
- https://play.google.com/console で登録。登録料は 25ドル（1回だけ）。本人確認（身分証）があります。
- **個人で登録した場合の決まり**: 一般公開の前に「クローズドテスト」を **12人以上・14日間以上** 続ける必要があります。知り合いに声をかけて、Googleアカウント（Gmail）を集めておくと早いです。

## 2. アップロード用の鍵を作る（あなた・1回だけ）
アプリに「作った人の印」をつけるための鍵です。パスワードは自分で決めて入力します（Claudeには教えないでください）。
```
powershell -ExecutionPolicy Bypass -File tools\make_upload_key.ps1
```
- 鍵は `C:\Users\<あなた>\rsr_keys\upload.keystore` にできます。**USBメモリなどにも必ずコピー**し、パスワードもメモして保管。なくすと更新版を出すのに手続きが必要になります。

## 3. ストアに上げるファイル（AAB）を作る（あなた）
```
powershell -ExecutionPolicy Bypass -File tools\build_android.ps1 -Store
```
- 鍵のパスワードを聞かれるので入力 → `Builds\Android\RhythmSlashRunner.aab` ができます。
- 出すたびに番号（バージョン）は自動で1つ上がります。

## 4. プライバシーポリシーをネットに置く（あなた）
- `store/privacy_policy.html` の【運営者名】【連絡先メールアドレス】（英語の部分も）を書き換える。
- 置き場所の例: GitHub Pages（無料）、Googleサイト（無料・中身を貼り付けるだけ）。
- できたURLをClaudeに伝える → アプリの「設定 → ライセンス」に「プライバシーポリシー」ボタンが出るようにします（`Features.PrivacyPolicyUrl`）。

## 5. ストアの掲載情報（あなた・中身はできています）
| 項目 | ファイル |
|---|---|
| タイトル・説明文（日英） | `store/listing.md` |
| アイコン 512×512 | `store/icon_512.png` |
| フィーチャーグラフィック 1024×500 | `store/feature_graphic.png` |
| スクリーンショット | `store/screenshots/ja/`, `store/screenshots/en/` |
| 紹介動画 | `store/video/preview_ja.mp4` を YouTube に上げてURLを登録 |

## 6. Play Console の質問への答え（あなた・下の通りに答えればOK）

**データセーフティ（データの扱い）**
- データを集めるか: **はい**（プレイ記録に同意した人だけ）
- 集めるもの: 「アプリのアクティビティ → アプリの操作」「アプリの情報とパフォーマンス → クラッシュログ・診断」「デバイスID」
- 目的: 分析（アナリティクス）
- 第三者と共有: **いいえ**（Unity は「サービス提供者」なので共有にあたらない）
- 暗号化して送る: **はい** ／ 削除を頼める: **はい**（設定でオフにすると削除を依頼）
- 任意かどうか: **任意**（同意しない人からは集めない）
- 支払い情報: Google Play が処理するので、アプリとしては集めていない

**コンテンツのレーティング（IARCの質問）**
- 暴力: 食べ物やおもちゃを斬るだけで、人や動物は傷つかない → 「アニメ・ファンタジーの軽い表現」程度。血の表現なし
- 性的表現・言葉づかい・ギャンブル・薬物: **なし**
- ユーザー同士のやりとり（チャット等）: **なし**
- アプリ内課金: **あり** ／ 位置情報: **なし**

**ターゲット年齢**: 「13歳以上」を推奨。13歳未満を含めると「ファミリー向けポリシー」の対象になり、使える分析ツールなどの審査が厳しくなります（あとから広げることはできます）。

**広告**: 「広告なし」

## 7. 課金アイテムの登録（あなた）
- Play Console →「収益化 → アプリ内アイテム」で2つ作る（種類は「消費アイテム」）。お金を受け取るための「販売者アカウント」の登録（銀行口座など）が先に必要です。

| アイテムID（この通りに入力） | 中身 | 価格の目安 |
|---|---|---|
| `rsr_drink_3` | エナジードリンク 3本 | 160円 |
| `rsr_drink_10` | エナジードリンク 10本 | 480円 |

- 登録が済むと、アプリのショップに自動で「3本パック」「10本パック」が出ます（それまでは隠れていて、代わりに「ドリンクの手に入れ方」が出ます）。

## 8. ランキング（あなた → Claude）
- Play Console →「Play ゲームズ サービス」でゲームを作り、リーダーボード「距離」（形式: 数値、並び順: 大きいほど上）を作る。週ごとの順位は Google 側で自動的に分けて表示されます。
- 表示される **リーダーボードID** と **アプリID** を Claude に伝える → 組み込みます。

## 9. プレイ記録（あなた → Claude）
- https://cloud.unity.com でプロジェクトを作り、Unity Editor の「Edit → Project Settings → Services」でつなぐ（つないだらClaudeに伝える）。
- つながるまでは何も送られません（ゲームは普通に動きます）。

## 10. クローズドテスト → 一般公開
1. Play Console「テスト → クローズドテスト」で AAB を上げ、テスターのGmailを登録 → 招待リンクを送る。
2. 14日間、12人以上に入れてもらう（遊んだ感想も集める）。感想を Claude に伝えれば直します。
3. 「製品版」へ申請 → Googleの審査（数日〜1週間ほど）→ 公開。
