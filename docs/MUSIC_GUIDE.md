# 曲の差し替え方（作曲家への依頼メモつき）

ゲームの曲は、ふだんはプログラムで作った音（合成音）です。録音した曲ファイルを置くと、その曲に置き換わります（置かなければ今まで通り）。

## 1. 曲ごとの名前（`track` に書く名前）

| 名前 | 使われる場所 | 今のテンポ |
|---|---|---|
| Kitchen | ステージ：巨大キッチン（最初のステージ） | 120 |
| ToyRoom / SkyOrchard / NeonMarket / CandyLand / Freezer | 各ステージ（2面以降は順番がランダム） | 130〜150 |
| Fever | FEVER 中 | そのステージのテンポ |
| BossOnion / BossToaster / BossIcecream / BossDonut / BossZenmai / BossKaminari / BossYukidaruma | 各ボス戦 | そのステージのテンポ |
| Home | ホーム・結果画面 | 92 |

ステージのテンポは 1面120、2面130、3面140、4面以降150 BPM です。

## 2. 作曲家にお願いすること

- **ループ**: 終わりと始まりがつながる曲（つなぎ目でプツッと鳴らない）。
- **長さ**: 4拍子で、きっちり小節単位（例：16小節 = 64拍）。1拍目から始める（前に無音を入れない）。
- **テンポ**: 120・130・140・150 BPM のどれか。ステージ曲・ボス曲は、できれば4つのテンポ全部で書き出してもらう（同じ曲をテンポ違いで）。1つだけでも動くが、ゲームが速さを合わせるときに音の高さも少し変わる。
- **形式**: WAV（44.1kHz または 48kHz、ステレオ）。
- **音量**: 最大が −1 dBFS 程度。効果音が埋もれないよう、低音を出しすぎない。
- **権利**: ゲームでの商用利用・ストアの紹介動画での利用ができる契約にする（作曲者の名前をライセンス画面に載せるかも決める）。

## 3. ゲームへの入れ方

1. ファイルを `unity_project/Assets/RhythmRunner/Resources/Audio/Music/` に置く（例：`boss_onion_150.wav`）。読み込みの設定は自動で決まります。
2. 同じフォルダに `music.json` を作り、1ファイル1行で書く:

```json
{ "entries": [
  { "track": "BossOnion", "file": "boss_onion_120", "bpm": 120, "beats": 64 },
  { "track": "BossOnion", "file": "boss_onion_150", "bpm": 150, "beats": 64 }
] }
```

- `file` は拡張子なしのファイル名、`beats` はループの長さ（拍の数）。
3. ゲームを起動すると、記録に `[Music] recorded BossOnion ← boss_onion_150 (150 BPM, 64 beats)` と出ます。

## 4. 知っておくこと

- 録音した曲は1つの層として鳴ります（合成音の曲のように、コンボで楽器が増えていく効果はありません）。
- 曲を入れるとアプリが大きくなります（1分のループで約1MB）。
- 曲ごとに差し替えられるので、まずはボス曲1〜2曲から試すのがおすすめです。
