# Rhythm Slash Runner

A vertical endless rhythm game made with Unity: a hamster runs on its own, and you slash what comes down three lanes in time with the music.

ハムスターが自動で走り、奥から来る物を3レーンで音に合わせて斬る、縦画面のエンドレス・リズムゲームです（Unity製）。

## Where things are

| Path | Contents |
|---|---|
| `unity_project/` | The game (Unity 6000.3.22f1, C#). Code: `Assets/RhythmRunner/Runtime` |
| `data/` | Note patterns and game data |
| `prototype_web/` | Early browser prototype (`npm test`, not the full game) |
| `GAME_SPEC.md`, `TECH_SPEC.md`, `UX_UI_SPEC.md`, `SOUND_SPEC.md`, `ART_BIBLE.md` | Specifications |
| `DECISIONS.md`, `DEVELOPMENT_STATUS.md` | Design decisions and current status |
| `store/` | Store listing text, screenshots, videos, privacy policy, release steps |
| `tools/` | Build, art, audio, translation and store tools |

Raw art sources (`art_generated/`) and finished builds are not in this repository.
